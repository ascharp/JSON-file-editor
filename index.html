How to Use

  1. Upload a JSON file using the "Choose JSON File" button
  2. Or click "Load Sample JSON" to try with example data
  3. Edit the configuration parameters in the form that appears
  4. Click "Export JSON" to download your updated configuration
  5. Use "Reset" to start over with a new file
