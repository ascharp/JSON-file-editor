How to Use

For JSON Configuration Files:

  1. Upload a JSON file using the "Choose File" button
  2. Or click "Load Sample JSON" to try with example data
  3. Edit the configuration parameters in the form
  4. Click "Export JSON" to download your updated configuration

For Python DAG Files:

  1. Upload a Python file (.py) containing an Airflow DAG
  2. Or click "Load Sample Python DAG" to try with example code
  3. Edit the extracted DAG configuration parameters
  4. Click "Export Python DAG" to download your updated DAG

General: Use "Reset" to start over with a new file. All changes are shown in a confirmation dialog before export.
